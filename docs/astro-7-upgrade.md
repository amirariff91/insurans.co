# Astro 6 → 7 upgrade

Branch `trial/astro7`, based on `c6905c4` (the commit live at https://insurans.co on 2026-11-13).
Static output, built with bun and served by nginx. Nothing outside the repo changes.

## Versions

| Package | Before | After |

| astro | 6.3.5 | 7.4.12 |
| vite (via astro) | 7.3.3 | 8.3.8 (Rolldown + Oxc) |

| --- | --- | --- |

| Rust compiler replaces Go compiler; unclosed tags and invalid nesting become errors | Checked, no errors | Build is clean. | `compressHTML` default `true` → `'jsx'` | Yes | See "Whitespace". |

| Experimental flags removed or stabilised (`logger`, `queuedRendering`, `rustCompiler`, `advancedRouting`, `cache`, `routeRules`) | No | No `experimental` block. |
| `@astrojs/db` and `astro db/login/logout/link/init` removed | No | Not used. |

## Whitespace

Astro 7's default `compressHTML: 'jsx'` removes whitespace that contains a line break between text, inline elements and
`{expressions}`. Measured in Chromium (`document.body.innerText`, whitespace collapsed) against the Astro 6 build,
`'jsx'` drops **251 distinct spaces (380 occurrences) on 81 of 180 pages**, for example "Pergi MyEGatau",
"Rujukan umum:myptv.my", "aggregator sepertiBjak.my atauPolicyStreetuntuk", "Rujuk halaman rasmii-Care",
"Utama›Insurans Kereta" in every breadcrumb, and the comparison and state link lists. The trial's 10 medical-card pages were only the most visible case.

**Decision: `compressHTML: true` set explicitly for this release.** Reasons:

- A framework upgrade should not change content. Fixing `'jsx'` properly means adding `{' '}` at dozens of places in
  page templates and shared components (Breadcrumbs, comparison links, state links, prose with inline links).
  The affected pages span 19 sections of the site. That is a separate, content-touching change that deserves its own review.
- An output diff can only check branches the current data renders. With `true`, the old HTML whitespace rules apply
  everywhere, including conditional branches no page renders today.
- `true` is a supported value in Astro 7, not deprecated.

The medical-card template (`src/pages/medical-cards/[slug].astro`) also gets an explicit `{' '}`, so it is correct under both
settings. The full list of spots that `'jsx'` would break is in the scratchpad file `jsx-whitespace-spots.txt` from this
run; regenerate it when that migration is done.

One more compiler difference remains under `compressHTML: true`. The Go compiler stripped whitespace inside JSX in
`{...map(...)}` expressions; the Rust compiler collapses it to one space. This adds whitespace-only text nodes in the NCD
option labels (`AnswerCard`, a flex container) and the NCD ladder rows (`NcdLadder`, a grid). Flex and grid containers
do not render whitespace-only text, so rendered text and pixels are unchanged (39 car model pages; see below).

## Bundle size

Rolldown does not tree-shake unused properties of a default-imported JSON object, while Rollup did. Three
browser-side libraries default-imported a whole data file and used one key, so with no change the home-insurance
calculator script grew from 3.3 KB to 72 KB, and the two roadtax calculators by about 2 KB each. They now use named
imports (`import { tariff } …`, `import { rates } …`).

Page scripts, Astro 6 → Astro 7 (bytes, minified): NCD calculator 5,114 → 5,081; coverage calculator 4,041 → 3,998;
roadtax 4,552 → 4,473; motorcycle roadtax 3,592 → 3,485; home insurance 3,338 → 3,264; AnswerCard 1,770 → 1,751;
ModelPicker 2,369 → 2,335. CSS 35,745 → 33,915.

## Equivalence (Astro 6 build vs this branch, same commit)

Script: `compare.py` (kept outside the repo). Browser checks: `innertext.js`, `behaviour.js`, `sweep.js` + `pixdiff.py`.

- **Files:** 290 in both. All 93 non-HTML files that share a name are byte-identical, including `sitemap-index.xml`,
  `sitemap-0.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`, all OG images, fonts and icons. The 14 `_astro/*` bundles have
  new content hashes. After hash normalisation the only difference is in the unused Preact renderer chunks
  (one `client.*.js` fewer, one `preact.module.*.js` more).
- **HTML (183 files, 180 pages + 3 redirect pages):**
  - title, meta description, canonical, robots, all `og:*` and `twitter:*`: identical on 183/183
  - JSON-LD (486 blocks, parsed): identical on 183/183
  - internal links (multiset): identical on 183/183
  - DOM structure (every element and attribute, after normalising `_astro` hashes and `data-astro-cid-*`): identical on 183/183
  - authored inline scripts (362, including the 360 GTM, consent-mode and AdSense snippets), whitespace removed:
    identical on 183/183. External script URLs (AdSense, GTM, bundles): identical on 183/183.
  - visible characters with all whitespace removed: identical on 183/183
  - visible text from the parser, whitespace collapsed, only block boundaries counted: identical on 144/183. The other 39
    are the car model pages, where the NCD flex labels and grid rows gain whitespace-only nodes (above).
    Rendered text is identical.
  - Astro-processed module script inlined into every page (the mobile-menu toggle, 1 distinct script): differs only
    in minifier output (Oxc: `var`/`let` and template-literal quotes vs `const` and double quotes, renamed locals). Logic
    is the same, and the browser test below exercises it.
- **Rendered text** (`document.body.innerText`, Chromium, whitespace collapsed): identical on 180/180 pages at 1280 px
  and 180/180 at 390 px. No console errors on any page in either build.
- **Pixels:** full-page screenshots of all 180 pages at 390 and 1280 px in both builds
  (360 pairs, final code): 350 pixel-identical; 10 differ in **one pixel** of the header logo at 390 px
  ((51,34), blue channel 247 vs 240). This is Chromium rasteriser noise, not a build difference: across two full sweeps the
  alternate value appears in the Astro 6 build too (1 and 5 times) as often as in the Astro 7 build (2 and 5 times), on
  different pages each run. The Axia and medical-card before/after screenshots at both widths are pixel-identical.
- **Behaviour** (both builds, 390 and 1280 px; same scenario, results compared as text): homepage incl. the mobile menu
  (open, Escape closes), Perodua Axia page (select NCD 30%, answer card updates), NCD calculator (RM 1,500 at 55% NCD,
  then the "should I claim" tool with RM 2,000 repair and RM 400 excess), comparison page (AIA vs Great Eastern),
  medical-card page (AIA A-Plus Health360), home-insurance calculator (RM 300,000 building, RM 50,000 contents),
  car roadtax (1,500 cc) and motorcycle roadtax (150 cc preset, 250 cc). All 14 results are identical between builds,
  with no console or page errors. Requests to googletagmanager.com, google-analytics.com, googlesyndication.com and
  doubleclick.net were aborted in the test browser.
